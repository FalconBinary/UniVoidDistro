# Русское руководство (исходный материал)

Главы `00`–`18` и `README.md` в этом каталоге — руководство **Void-Hardened-Refurs** на момент
переноса (коммит 8af9d04 + рабочее дерево). Они описывают систему, с которой начинается
void-hardperf-light, и служат источником для английских глав, которые пишутся по вехам
([../ROADMAP.md](../ROADMAP.md)).

Отличия от текущего репозитория:

- все сообщения программ и комментарии переведены на английский; цитаты русского вывода в этих
  главах соответствуют английским строкам (см. контракт в `tests/vm/vmlib.py`);
- `tests/vm/check.py` стал реестром шагов (`tests/vm/steps/*.py`);
- `vh-audit` разбит на `rootfs/usr/local/libexec/vh/vh-audit.d/`;
- каталог репозитория в VM — `/root/void-hardperf-light`, а не `/root/void-hardened`.
