Rules that apply (22):
  arm.iommu.iort [cpu-arm.zon]: An ACPI ARM machine describes its SMMU in the IORT table [VERIFY: IORT may describe the I/O topology without an SMMU]; the machine kernel gets the SMMU drivers built in.
  arm.kernel [cpu-arm.zon]: The machine kernel's ARM64 class: the generic timer, PSCI, CPPC or SCMI frequency control, the errata of the cores.
  arm.mcpu.generic [cpu-arm.zon]: Any other ARMv8 core: -march=armv8-a, the instruction set every ARM64 CPU has.
  arm.aes [cpu-arm.zon]: The ARMv8 Crypto Extensions: AES-XTS through the ce-blk driver, built into the machine kernel.
  gpu.virtio [gpu.zon]: The virtio GPU of a virtual machine.
  gpu.renderer.gles2 [gpu.zon]: A GPU with a DRM driver: RefursWM renders with GLES2.
  gpu.renderer.vm [gpu.zon]: A virtual machine without accelerated 3D: RefursWM renders with pixman (the CPU) [VERIFY with virgl].
  net.wired.dhcp [net.zon]: A wired interface and VH_ETH auto or dhcp: dhcpcd on eth0 (the kernel names interfaces with net.ifnames=0).
  class.vm.dmi [platform.zon]: The firmware of a virtual machine names its maker: QEMU, VMware, VirtualBox, Xen, Parallels.
  class.desktop [platform.zon]: Every other machine.
  class.vm [platform.zon]: The virtual machine class: no microcode, no power management.
  acpi.power-button [platform.zon]: An ACPI power button (PNP0C0C, or the fixed LNXPWRBN).
  acpi.power-button.tiny-off [platform.zon]: tiny_power_button and button both match a control-method power button (PNP0C0C), and the first to load wins; tiny_power_button provides no input device, so vh-acpid would never see the button (found on the test bench, kernel 6.18.57).
  acpid.button [platform.zon]: vh-acpid handles the power button (a regular poweroff by default).
  tpm.tools [platform.zon]: A TPM 2.0: tpm2-tools reads the measurement log (the Option ROM check before key enrolment) and serves tpm2-totp.
  tpm.tis [platform.zon]: A discrete TPM through the TIS interface (LPC or SPI).
  usb.common [platform.zon]: What a USB port must handle after the module lock: storage, keyboards and mice, audio.
  camera.off [platform.zon]: VH_CAMERA=no: the UVC driver is refused (the firmware setup can disable the camera outright, which is stronger).
  cardreader.off [platform.zon]: VH_CARDREADER=no: the Realtek card reader's drivers are refused.
  watchdog.softdog [platform.zon]: No hardware watchdog known: softdog, which does not survive a hung kernel (a row in the cost table).
  storage.nvme [storage.zon]: An NVMe disk: the driver built into the machine kernel (the root disk is behind it before the initrd can load anything).
  storage.trim [storage.zon]: A fixed disk that accepts discard and VH_TRIM=yes: fstrim once a week (SSD speed and wear levelling; the cost is that the disk shows which blocks are free).

Requirements not met (1):
  secure-boot: Secure Boot with the system's own keys verifies the bootloader and the UKI before they run.
    residual risk: The boot chain is not verified: an evil maid can replace the kernel and capture the LUKS passphrase.
    fix: Enable Secure Boot support (Custom or Standard mode) in the firmware setup; the system enrols its own keys after the first boot (install/20-firstboot.sh).
